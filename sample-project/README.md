# avec-moi sample project

Open this folder in the `runIde` sandbox IDE to dogfood the plugin.

- The plugin starts its MCP server on `http://localhost:32684/mcp` when this project opens.
- `.mcp.json` points Claude Code at that server.
- Run `claude` in this project's terminal; `/mcp` should list the `avec-moi` server and its tools.
